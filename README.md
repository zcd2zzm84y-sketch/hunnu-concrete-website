# Хүннү Конкрет — Ажилтны үнэлгээ

Ажилтны мэдлэг, ур чадвар, сэтгэл ханамжийн онлайн үнэлгээ. Netlify дээр ажиллана.

- `public/index.html` — ажилчдын бөглөх хуудас (утас, компьютер).
- `public/admin.html` — HR самбар: ажилтны паспорт, сэтгэл ханамжийн нэгдсэн дүн. `ADMIN_KEY` нууц үгээр нэвтэрнэ.
- `public/assets/data.mjs` — асуултын сан, алба, албан тушаал. Асуулт нэмэх, засахдаа энэ файлыг өөрчилнө.
- `netlify/functions/submit.mts` — хариулт хүлээн авч Netlify Blobs-д хадгална. Сэтгэл ханамжийн хариулт нэргүй, зөвхөн алба, ажилласан хугацаа, сартайгаар тусдаа хадгалагдана.
- `netlify/functions/admin.mts` — HR самбарын API. Сэтгэл ханамжийг зөвхөн нэгтгэж (3-аас цөөн хүнтэй бүлгийг задлахгүй) буцаана.

Netlify-д тохируулах: Project configuration → Environment variables → `ADMIN_KEY` (Functions scope).
